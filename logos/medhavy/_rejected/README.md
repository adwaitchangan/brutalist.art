# _rejected — out of the lottery, not deleted

`logo.py` globs `logos/medhavy/*.svg`, so a subdirectory removes these from the
random draw without destroying anything. Restore by moving a file back up.

Every mark here exists (or existed) under **two names** — the `medhavy-selected-*`
series is a byte-identical rename of `medhavy-logo-12` … `-33`. Both copies had to
move or the mark would still be drawable.

| File | Wordmark | Why |
|---|---|---|
| `medhavy-logo-01.svg` | **Medhaay** | misspelled — two a's |
| `medhavy-logo-08.svg` | **MEDHVAY** | misspelled — transposed |
| `medhavy-logo-15.svg` · `medhavy-selected-03.svg` | **Medh◌vy** | decorative glyph replaces the `a` |
| `medhavy-logo-30.svg` · `medhavy-selected-2-06.svg` | **SANDANCAT** | different company |
| `medhavy-logo-31.svg` · `medhavy-selected-2-07.svg` | **samandcat** | different company |
| `medhavy-logo-32.svg` · `medhavy-selected-2-08.svg` | **sandamcat** | different company |
| `medhavy-logo-33.svg` · `medhavy-selected-2-09.svg` | **sandamcat** | different company |

The correct spelling is **Medhavy** (Bear, 2026-09-01).

Verified by rasterising each mark at 620px and reading it — the wordmarks are
outlined paths, so no amount of grepping finds them. See the reel's
`_qc/medhavy-pool-audit.png` for the labelled 54-mark sheet this came from.
