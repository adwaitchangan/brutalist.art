# Logos

**What this is.** One folder per company: `icons/logos/<company>/<company>-NN.svg` plus a 1024 px `<company>-NN.png`. **Why.** Bear's LOGO LAW (2026-10-12): when a film refers to a company, product or tool, it shows the logo, not a text label. **Found.** `claude/` holds six marks (`claude-01` starburst is the default; `-02` pixel crab; `-04` app tile; `-05` black). Add a folder when a film needs another company; create the mark from the company's own public logo and name it `<company>-01`.

## The curated set (2026-10-13)

**What this is.** 192 more company, product and tool marks (193 folders with Claude), installed from the brand pack Bear dropped at `brutalist.art/logos/BrandsLogoSVG.zip` (6,435 brands, 18,473 files; only the useful ones were taken). **Why.** The LOGO LAW needs a mark ready before a beat names a tool. **Found.** Every mark is cropped to its drawing, centred on a square 1024 canvas with its longest side at 800 px (equal padding), full colour where the pack has one, otherwise the dark-ink variant, and each was checked for visibility on the cream stage. SVG and 1024 PNG share one name: `<slug>/<slug>-01.svg` and `.png`.

**Not in the pack, so still missing:** Aider, Droid (Factory), Apptainer, Slurm, Northeastern's own mark lives in `../../logos/northeastern/`. Marks that are really wordmarks or generic glyphs were left out (Pinecone, ssh).
