First, the anatomy. Nopunt is one file — SKILL dot md — and it does five

renders it. It fixes the SHOW slash HOLD slash CARD vocabulary that every

same bug in different hats. And it stays synced with the actual scene

## B04 — MECHANISM 1 · 27.95 s · SkillTeardownMechanism
First design decision, and it is the whole rule. HOLD versus PUNT. HOLD means
the beat needs a genuine archival photograph — a real person, a real place, a
real document, a real event — or a judgment only Bear can make. That is the
only legitimate placeholder. Everything else is a PUNT. A slot the system
could draw itself but deferred. Every row in the catalog below is animatable.
So if a beat's content appears in the catalog and is left unfilled, that is a
bug — not a design choice, not a stylistic hold, not a taste question. Author
it.

## B05 — MECHANISM 2 · 36.44 s · SkillTeardownMechanism
Second decision. The catalog. Every beat's narration has a shape, and the
catalog maps that shape to a form and to the tool that renders it. Six
families. Data and quantity — bars, stat cards, donuts, itemized lists.
Structure and relationship — grids, funnels, flow diagrams, stacks, gates.
Math and mechanism — equations built term by term, geometric transforms.
Enumerated concepts — FormB cards, one icon per named thing. Code and app and
interface — the real artifact, in the real skin. And text bookends — FormA
and the four fixed beats. If a beat's content lands in any of these families,
the tool is already picked. The author's job is just to route it.

## B07 — MECHANISM 4 · 33.17 s · SkillTeardownMechanism
Fourth decision, and it is the vocabulary every authoring loop reads. SHOW,
HOLD, or CARD. SHOW — a real skin surface, a Manim diagram, a Remotion
scene, or a legible artifact renders the beat's content, and its component is
named in the shot block. HOLD — a real archival photograph, or a judgment
only Bear can make, with a one dash line hold underscore reason next to it.
CARD — a few words with nothing to show, an act divider or an aphorism, last
resort. If a card's narration names a visual or makes a factual claim, that
is a PUNT, not a card. Anything outside these three is a PUNT — a bug, not a
style choice.

## B08 — FALSIFIABILITY · 33.26 s · SkillTeardownMechanism
Falsifiability. What if the catalog does not fit. It happens. A concept lands
that has no row — nothing moves, no listable set, no code artifact, no real
photo. Nopunt is explicit about this case. It is a scripting gap to FLAG —
never a gen dash AI clip, never an archive still, never a card of words
dressed up as a beat. The search writes the miss to TEMPLATE dash MISSES dot
md by itself, with dash dash reel pointing at the reel that needed it, and
the next author sees the ask. A miss is a design task. Build the component
and the next reel finds it forever. But a miss is never a licence to slate.
