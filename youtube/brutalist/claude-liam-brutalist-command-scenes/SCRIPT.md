## B03 · MECHANISM  ·  23.70 s  ·  `ClaudeCodeBeat`

> The library the script searches is a single JSON file at
> runtime/remotion/src/scenes.json. Six hundred and twenty renderable
> compositions. Each record has an id, an aspect, a folder or group tag, a
> description, synonyms, and its props. That schema is what makes ranking
> possible — every record has the same shape, so the searcher can score
> them uniformly. The file is a build product, regenerated by art
> scene-index.

## B04 · MECHANISM  ·  27.35 s  ·  `ClaudeCodeBeat`

> The ranker has one job: put the right lead at the top. Three trust
> tiers. An id hit is worth three points. A synonym hit is worth two. A
> hit anywhere else in the haystack — the description, the folder, the
> props — is worth one. Then it re-weights by inverse document frequency.
> That means a rare word like sankey outranks a common word like flow, so
> 'sankey flow' finds FinanceSankey and not every SourceFlow in the set.
> And a derived-only entry loses half a point, so a scene that actually
> describes itself outranks a guessed one.
