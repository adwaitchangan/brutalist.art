## 6. Idempotence — the >50KB skip on line 315-319

   If <book>/youtube/<reel_slug>/<reel_slug>-slate.mp4 already exists AND
   is larger than 50000 bytes, build_one() returns 'SKIP' with note
   '<KB>KB' and never re-captures the sim. To force a rebuild, delete
   the slate mp4 first.
