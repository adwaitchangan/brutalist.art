## Corrections and honesty log

- No sensationalized numbers. The 7,330 / 376 counts are quoted directly from
  `icons/icons.json → count` and a Python `sum(1 for i in icons if i['brand'])`
  computed live on the same file; both are logged in FACTCHECK.md.
- `--show <bogus>` exit code differs from `--show <valid>` (exits 1 vs 0) and
  from a search miss (exits 0). The beat sheet does not spend a line on
  `--show <bogus>` — the falsifiability beat (B08) uses the search miss because
  it carries the tool's own anti-redraw doctrine as an on-screen line.
- No AI-generated media. Every visual is a deterministic Remotion scene
  registered in Root.tsx. See PROMPTS.md for the composer prompts (typed
  on-screen, never sent to any API).
- No human signature was reused from the example beat sheets; those files
  were read as leads and their original folders are untouched.
