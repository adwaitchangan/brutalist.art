This is a **rehearsal**, not a live agent call — no clone or install was executed on-camera. The commands shown are the ones a real Claude Code session would issue.

- No Anthropic API key or Claude account credential is entered anywhere in the reel.
- The paste-ready handoff prompt (parent B08) is not in the Short. It lives in the full film.
