## B02 — FRAMEWORK: what a skill IS
> A skill is a folder. A SKILL file at the top — the doctrine Claude reads
> before doing anything — and the files it references. For ai-explainer, that
> means the register prose, the brand file, the outro lock, the pipeline safety
> notes, and the parent explainer chassis it extends. The instructions govern;
> the code just executes them.

## B03 — FRAMEWORK: the pipeline
> The skill runs one pipeline, always in the same order. Scaffold the folder and
> brand metadata. Write narration in the Teardown register. Generate the voice
> locally with Kokoro — that's the clock. Fill each beat's visual slot from
> Remotion scenes, Manim fragments, or Onda code blocks. Then compile to a four
> K master beside the reel. Never uploads. Never publishes.

## B04 — MECHANISM 1: the bookend spine
> The first design decision is the shape of every reel. Cold open on the Claude
> composer. Beat two is a hesitant writer, correcting a real misconception into
> the reel's actual claim. The body illustrates. The verdict is an artifact
> card. The handoff types a paste-ready prompt. The outro restates the title.
> Same six moves, every episode.

## B05 — MECHANISM 2: ILLUSTRATE LAW
> Second decision. The Claude interface only appears where the interface is the
> subject — cold open, ask beats, verdict, handoff, outro. Every other beat has
> to ILLUSTRATE its concept: a diagram, a Manim fragment, an Onda code block, a
> Remotion illustration. Two composer beats in a row is the smell. Seven videos
> of composer wallpaper is the failure this law exists to prevent.

## B06 — MECHANISM 3: ASK → RESULT
> Third decision. Whenever the reel is about to show a generated visual, it
> first shows the Claude prompt that made it. Composer beat with the ACTUAL
> prompt typed in, then the graphic. Never a rendered chart alone — always the
> ask, then the receipt. That habit is why this brand feels like the tool it's
> teaching, not a slideshow about it.

## B07 — FALSIFIABILITY: where it bites
> Here's where the skill bites. The instructions govern everything, which means
> an unread paragraph is a silent bug — a stale outro handle, a missing Beat
> two, a wallpaper reel. The lint helps, but the discipline is human. And Liam
> is a named substitute, never a Bear clone. If a reel needs Bear's voice, you
> rebuild it on the Bear channel. That's a one-variable change, not a
> re-authoring — but it IS a change, and the skill will not fake it.
