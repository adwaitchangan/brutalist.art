## claude-liam-brutalist-command-list-slate

Salam this is Liam in for bear. Every fellow in Brutalist has typed dot slash art dash dash list at some point. What it does is smaller and more literal than most people think. It prints a hand type table of 16 skills, no lookup, no directory scan. Here's exactly what runs and where it stops. Watch the writer walk this back. Art dash dash list does not run a skill in the toolkit. It prints the skills catalog. 16 rows, one dispatcher hard coded in the file itself. The whole dispatcher is one bash case statement. The second branch of that case is two aliases joined by a pipe dash dash list in the bear word list. Both hit the same body. You never need to remember which spelling the case pattern takes both. Here's the body, one print for the header than 16 more prints, one per skill. Every row is a literal string in the file itself. There's no file system scan, no plugin discovery, no configuration file. If a skill is missing from the table, it is missing because nobody added its print. This is the actual output on my terminal. 17 lines, a header row that reads skill and role than 16 skills sorted the way the file lists them. Builders first then personas then doctrines, no colors, no pager, it prints, it exits zero, it is done. The format string is worth reading. Percent dash 22s space, percent s backs flesh in. That means left pad the first field to 22 characters, one space then the second field then a new line. Every row is a line to the same 22 character gutter, which is why the table is scannable without a mono space aware terminal. Watch what happens with extra arguments. Dot slash art list Fubar prints the same 17 lines and exits zero. The branch never reads the rest of the command line. Compare that to a runner branch like Scenes or Run, which passes every remaining argument straight to a Python script. List is a printer, not a runner. Now the near miss dot slash art dash list with one dash instead of two does not print the catalog. It falls into the star branch and exits two with one hint line pointing you a dash dash list. Notice where that line lands, it is on standard output from a bear echo. If you pipe standard out to a file, the hint disappears and only the exit code is left behind. The recovery is two commands, dot slash art dash dash list to see every skill by name. Then dot slash art followed by the skill name and dash dash help to open that skill skill dot md in your pager. So the arc is list to see what exists then help on a specific skill to read what it does. Two commands, whole surface. So the split art dash dash list is a printer, two aliases one branch, a hand maintain table of 16 skills. Extra arguments are ignored, single dash and unknown tokens exit two with a hint. If you want to actually run a skill, you type its name after art. If you want to read what it does, you add dash dash help. Your turn, paste this into cloud code from the brutalist toolkit route.
