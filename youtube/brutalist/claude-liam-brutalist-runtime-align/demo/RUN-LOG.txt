# never has to render "nineteen twenty-six".

################################################################################
# SECTION 6 — the failure surface (the real fresh-box failure)
#   Run with the sandbox proxy in place and NO HF cache: the CTranslate2 model
#   fetch inside faster-whisper cannot reach huggingface.co, so WhisperModel()
#   raises before a single word gets timed. align.py itself does NOT catch this
#   — the fellow sees the raw traceback ending in either
#     ImportError: Using SOCKS proxy, but the 'socksio' package is not installed
#   or (on an ordinary box)
#     ConnectionError / URLError to huggingface.co
#   The lesson: the pip line in align.py's docstring
#     "pip install faster-whisper (CPU is fine; downloads a small model on first run)"
#   is a two-step guarantee — the pip install itself, AND the first run's
#   network fetch. Run one warm-up locally before the pipeline needs it.
