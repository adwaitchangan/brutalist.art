## Audit artifacts and limits

`audit.json` records hashes, master selection, probes, candidates and sample origins. `review-notes.json` records the actual visual review conclusions. `NN-contact.jpg` shows available local beat media at 70%; `NN-master.jpg` samples the actual selected master without assuming stale sheets align to it. The largest root/mp4 file was selected to match isdone.py. Missing cached beat files, missing raw receipts and missing source matches are disclosed, not silently treated as PASS.

Specific pixels were sampled, not every animation state. Run 15/50/85% beat-level QC, formula reveal-state checks and actual execution tests during each repair. Primary-source attribution and scholarly claims require a separate full fact-check.
