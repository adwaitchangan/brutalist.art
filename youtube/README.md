# Brutalist films

The [Brutalist playlist](brutalist/README.md) teaches fellows to make research
reports with Claude Code and this public toolkit. Every episode uses the
AI Explainer format and **Liam, in for Bear** (local Kokoro `am_onyx`). No captions.

Start with [Watch and Review](brutalist/WATCH.md). This is a local production
queue, not a published YouTube playlist. Source lives in GitHub; MP4s, MP3s and
large generated media stay out of Git and can be handed off through Drive.
